# جسر (Jisr)

تطبيق VPN لأندرويد (Kotlin + Compose) يعتمد على محرك Xray، بتصميم زجاجي بألوان البني الطوبي والرمادي والتركوازي.

## بناء الـAPK من الجوال (بدون كمبيوتر)
1. ارفع محتوى هذا المجلد إلى مستودع GitHub.
2. افتح تبويب **Actions** ثم شغّل **Build APK** (يشتغل تلقائياً مع كل رفع).
3. بعد انتهاء البناء نزّل **jisr-apk** من أسفل صفحة التشغيل، فك الضغط، وثبّت الـAPK.

## الاستخدام
انسخ رابط سيرفرك (vmess:// أو vless:// أو trojan://) ← تبويب السيرفرات ← "إضافة من الحافظة" ← الرئيسية ← اتصال.

## تنبيه
ربط المحرك بالنفق (ملف `vpn/XrayEngine.kt`) لم يُجرَّب على جهاز حقيقي، وهو أول مكان يُراجَع إذا تعذّر الاتصال.
